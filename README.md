# Frontend — Sistema de Gestão de Consórcios

Frontend da aplicação desenvolvido com **React, TypeScript e Vite**, responsável pela construção das interfaces, navegação e experiência do usuário.

## 🚀 Tecnologias

- React
- TypeScript
- Vite
- React Router
- CSS
- Git e GitHub
